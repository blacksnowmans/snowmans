Claude's New Desktop App Can Now Control Your Mac — And Yes, It Can Send Your KakaoTalks

October 28, 2026

Anthropic's newly updated Claude desktop app features a project-based AI agent that can take over your Mac's screen and mouse to automate repetitive tasks like sending KakaoTalk messages.

  • Task-specific "rooms": The new project feature lets you set goals and reference materials once, so Claude remembers the context without you needing to explain it every time.
  • Screen control: With computer-use enabled, Claude can open apps like South Korea's dominant messaging app, KakaoTalk, and type out messages automatically.
  • Human-in-the-loop safety: While powerful, the system requires careful permission management and strict prompt boundaries to avoid accidental data leaks or misdirected messages.

For tech-savvy professionals, this marks a massive shift from passive chat to active agency. Previously, getting an AI to interact with your local computer environment meant constant prompting and repeating context for every new chat. The new desktop app changes that by merging local file system access with Claude's reasoning capabilities, effectively turning the AI from a chatbot into an active co-worker sitting on your desktop.

The practical demonstration of Claude opening KakaoTalk, reading local text files, and queuing up messages highlights how close we are to frictionless workflow automation. However, granting an LLM access to your screen, clipboard, and messaging apps introduces real security risks. Users must carefully manage permission prompts—opting for "allow once" during testing—and set clear boundaries, such as commanding the AI to pause right before hitting the send button, to keep automation from turning into chaos.
