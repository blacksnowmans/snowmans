Anthropic’s AI-Led Rust Shift and Rising GitHub Supply-Chain Threats

November 28, 2026

Anthropic has replaced its Python-based Claude message API with Rust in a refactoring led by its own AI agents, cutting CPU usage per request by 70%.

  • Hiring and workflows upended: Anthropic engineers verified the AI-generated Rust code in just one week, and the company is abandoning traditional algorithm coding interviews to evaluate candidates on how effectively they direct AI agents to solve real problems.
  • Supply-chain attacks escalate: Malware designed to execute during local testing or pip installations has been found in more than 375 GitHub projects, while North Korean hackers are using the Ethereum network to conceal command-and-control servers and attackers are hijacking downloads for utilities such as Q-Dir and DesktopOK.
  • Fresh alternatives in AI hardware and models: Nvidia released non-commercial weights for a free autoregressive image-generation model to challenge diffusion systems, while hardware reviewers eye compact options like the Asus UGen300 USB AI accelerator for running smaller models locally.
  • Developer priorities diverge: On GeekNews, a popular South Korean developer forum, attention centered on Relic, a Python-based disassembler and decompiler for security analysis, alongside new roadmaps showing developers how to assemble AI agents in 12 steps or about 80 minutes.

What the shift means

Taken together, these updates point to a sharp split in what makes software engineers valuable—and vulnerable. Python remains the default glue for building AI agents and rapid prototypes, even as coding education expands into public schools in Nigeria and university competitions in Vietnam. Yet Anthropic’s rewrite shows that once systems scale, companies are willing to let AI agents port performance-critical bottlenecks into Rust, leaving humans to act as reviewers and system architects rather than line-by-line coders.

That shift turns traditional career ladders upside down, especially for junior developers. When an AI agent can generate complex infrastructure code faster than a human can write it, grinding through whiteboard sorting puzzles matters far less than spotting subtle architectural flaws and security holes. Impact and judgment are replacing hours logged and syntax memorized as the core metrics of engineering performance.

The catch is that faster AI-assisted development is colliding with a collapsing baseline of trust across open-source tooling. With state-backed North Korean actors hiding malware infrastructure on blockchains and trojanized downloads slipping onto legitimate channels, blindly running unfamiliar GitHub code or Python packages on a work machine is now a direct path to compromise. Moving fast with AI agents only works if verification and dependency hygiene keep pace.
