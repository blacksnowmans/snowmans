How Baton Links Claude, Codex, and Hermes for Multi-Agent AI

October 10, 2026

A new plugin called Baton solves the friction of multi-agent AI by letting users connect different systems like Claude, Codex, and Hermes directly, eliminating the need to manually copy and paste between windows.

  • What happened: Baton acts as a communication protocol plug-in for desktop apps, letting one AI agent automatically pass outputs and tasks to another without human errand-running.
  • How it works: Users set up the plugin via simple commands in Claude or connect via Discord bots and remote servers using Kanban-style task cards.
  • What it changes: It transforms isolated AI models into a collaborative multi-agent workforce, bringing decentralized computing closer to everyday desktop workflows.
  • Who is affected: Developers, content creators, and power users who rely on multiple AI tools and want to bypass the steep learning curve of terminal-based automation.

Moving Beyond Manual Copy-Paste Workflows

Using multiple advanced AI models often turns humans into glorified middle managers. Copying a result from Claude, pasting it into Codex, and moving the output back defeats the promise of true automation. While terminal-based multi-agent setups have existed, their technical barriers and Windows-Mac compatibility issues make them impractical for everyday users.

Baton changes this by moving communication protocols directly into accessible desktop applications. A single prompt in Claude can trigger Codex to generate images and Hermes to handle remote server tasks, routing files and updates seamlessly in the background. By integrating tools like Discord bots and remote virtual private servers (VPS) through standardized task routing, the setup bridges local and remote environments without heavy engineering.

The Push for Open Standards and Data Safety

As multi-agent ecosystems expand, the race for communication standards—such as Google's A2A protocol and Model Context Protocol (MCP)—is heating up. Without open standards, users risk falling back into closed tech-monopolies. Furthermore, connecting multiple autonomous agents introduces security risks, notably "trust contamination," where bad or unverified data from one agent cascades rapidly through the entire connected network.

To combat these risks, industry proposals like South Korea's LG AI Research point toward adopting Artificial Intelligence Bills of Materials (AI-BOM) to track dataset transparency and licenses. Just as open communication protocols prevent data monopolies, rigorous verification ensures that automated systems do not inherit hidden vulnerabilities from external sources.
